# Operator and calibration guide

## Build a mapping without a projector

1. Open the compact output dropdown and choose a virtual canvas size, or enter a custom size for a non-standard projector aspect ratio. Custom virtual canvases support 320–7680 × 240–4320 pixels. The resizable window displays the same rendered surfaces as a physical output.
2. Import test images, videos or live sources into the **Clip Grid**. Use **Assign To** to choose a mask output, then click a clip to map it directly to that mask. Video clips begin playing when assigned. Use the layer button on a clip to create a composition track; select a track and click a different library clip to load it into that track's clip slot.
   To create content without a file, open the **+** menu beside Clip Grid and choose a preset under **Generated Visuals**. Presets include warm/cool solid colour, animated gradients, a night sky and soft clouds. The selected preset is added to the clip grid and assigned to the current mask; use its sliders button to edit colour and motion. Its configuration travels with the assignment in show files and mapping presets.
3. The **Main Surface** shows the composition layer grid. Add quadrilateral, triangle, circle, ellipse or editable polygon surfaces from **Mask Outputs**. You can create a cross mask from several polygon masks, or shape a ceiling mask with the same polygon and keystone tools.
4. Use **Duplicate** on a configured mask output to create another surface with its current geometry, media assignment and settings, then adjust its name and mapping independently.
5. For a church setup, create a polygon mask and add vertices around the cross. Add another polygon or quadrilateral mask for the ceiling area. Assign a different NDI source to each mask, or put sources in separate composition tracks and map the stack to a surface. Each mask keeps independent source content, corners, mesh warp and vertices while sharing one projector output.
6. To use more than one display, open each physical screen or virtual canvas from the output menu. Assign each surface to its destination from **Output Geometry**. The mapping preview follows the selected surface's output; use its output picker to inspect other canvases. Mapping and show files save output assignments.
7. The composition grid has one clip slot per layer track. Click a track's slot to choose a source, or select the track and click a clip in the library to load it. The right panel shows the top layer in front. Use the up/down arrows to change stacking order; use **S** to solo a layer. Multiple soloed layers play together, while non-solo layers are temporarily hidden. Open the layer's **…** menu to rename or duplicate it, or lock its controls. Each track has independent position, scale, rotation, skew, opacity and effects. Layer order, names, solo state, locks and transforms save with the show and scenes.
8. Map the layer stack to a surface from that surface's **Content** menu. Clear the layer stack assignment when you only want independently assigned masks to receive content.
9. Select a mask output and drag its numbered white handles to keystone-correct it. Drag a cyan **T/R/B/L** edge handle to move both corners on that side together. In **Output Geometry**, narrow or widen the top, right, bottom or left edge independently, or use the horizontal and vertical keystone buttons for symmetric adjustments. Choose a fine, medium or coarse step, enter precise coordinates for each corner, or use the per-corner reset, whole-surface move, scale and rotation controls. Enable **Mesh Warp** for curved or irregular surfaces, choose a 2×2 through 6×6 cell grid, then drag the purple interior controls. Grid changes retain the existing warp through interpolation. Use the mapping toolbar's **Move** tool to drag the whole surface. **Undo/Redo** and ⌘Z / ⇧⌘Z affect geometry edits.
10. Use **Input Selection** in **Output Geometry** to crop and orient the source inside the calibrated surface. Adjust horizontal/vertical zoom, source position and rotation, skew the image or flip it horizontally or vertically. These controls change the content sampling while leaving the output corners and mask outlines in place. **Reset** restores the untransformed source. Layer tracks have matching independent controls.
11. Choose **Mask** on the mapping toolbar or **Edit Vertices** in the inspector to enter mask editing. Only mask points respond in this mode, which prevents an accidental corner drag. Drag a numbered vertex, tap the larger **+** on an edge to insert there, or right-click a vertex to remove it. Select a point from the numbered strip or cycle to adjacent points. Enter source-coordinate percentages or use the larger fine, medium or coarse arrow nudges in output space. Turn on the grid button to show guides and snap points to 1% increments. Zoom with the magnifier controls or scroll to pan; **Fit** returns to the full canvas.
12. In **Mask Paths**, select **Main** or add a region/cutout. The plus/minus path icons distinguish included regions from cutouts. Selecting a path switches the canvas to vertex editing for that path. Add a region to include a second disconnected area; add a hole/cutout to subtract a polygon from the visible mask. Select an added path to change it between include and cutout, or delete it with the trash button. Added paths can be moved and edited with the same numbered handles, edge insertion, vertex removal, coordinate fields and output-space nudges.
13. Adjust mask edge feather, brightness, surface opacity, visibility or blackout independently. Set per-edge blend widths on the assigned output when projector images overlap; widths are percentages of that output canvas. Use **Global Output Exclusions** to add a polygon or circular exclusion after all surfaces are warped. Select it to drag the pink vertices, insert or remove points, and tune its shared soft edge. These regions stay fixed in output coordinates. Expand **Colour Correction** for contrast, saturation, exposure, gamma, RGB gains, grayscale, sepia and invert. These adjustments belong to the selected mask output; use its reset button to return to neutral. Lock a surface after calibrating it to prevent accidental geometry edits.
14. Expand **Effect Stack** to add blur, chroma/luma key, brightness, saturation, hue rotation, tint, sharpen, vignette, threshold, grayscale, sepia, invert or pixelation to the selected surface. Toggle an effect to bypass it, use the arrows to change its order, tune its controls, or remove it. Apply built-in **Soft Focus**, **Green Screen Key** and **Blue Screen Key** presets, or save, reuse and delete your own effect stacks. Effects are saved with mappings and shows and recalled with scenes.
15. Expand **Effects** under a layer track to apply effects before it is mapped. Layer effects have independent order, enable state and parameters, and can use the same saved presets. Open the diagonal-arrows control to zoom, position, rotate, skew or flip that layer's source independently of the surface's input and output mapping; reset the layer transform without changing its calibrated corners or mask.

Imported video starts muted. Use the repeat button on a video clip to loop it; clips otherwise play once and hold their final frame. Loop state is remembered per file and recalled with scenes and shows. Open the sliders control to scrub the timeline, step by one 30 fps frame, jump five seconds or choose playback speed from 0.5× to 2×. Scene and show recall preserve playback position and speed for videos assigned directly to a mask as well as videos in the layer stack. Open the speaker control to see its live audio meter, mute/unmute it, set its source volume, or add 0–500 ms of audio delay to sync the clip with its picture. If the clip has no audio track or its format cannot be processed, ProMap explains why the meter or delay is unavailable. **ProMap → Settings → Audio output device** routes video audio to a selected macOS device or **System Default**; use **Refresh** after connecting hardware. **Master media volume** scales all video source levels together. Output device and master level are application preferences.

## External control

Open **ProMap → Settings → General** to select a projector output rate from 24, 25, 30, 50 or 60 fps and set the in-app preview rate separately from 5 to 30 fps. Lower preview refresh reduces editor GPU use without changing projector output or saved mapping coordinates. Projector output rate changes apply to open outputs immediately. Open **ProMap → Settings → Network** and enable **HTTP control API**. It is disabled by default and binds to `127.0.0.1`, which is suitable for FreeShow running on the same Mac. FreeShow's [Send REST Command action](https://freeshow.app/api) accepts a URL, method, content type and payload. Set Method to `GET`, leave Content Type and Payload empty, and paste a URL from ProMap's Network settings. For example, `http://127.0.0.1:8765/v1/blackout/on` blacks out program output, `/v1/blackout/off` restores it, and `/v1/output/intensity?value=0.5` sets master intensity to 50%. `/v1/output/active?value=false` and `?value=true` set or clear master blackout; these controls do not open or close output windows. Use named mask routes like `/v1/surface/blackout?name=Church%20Cross&value=true` or `/v1/surface/intensity?name=Ceiling&value=0.5` to control a mask without copying its UUID. Names must be unique; `/v1/status` lists exact names and IDs. The port in the URL must match the port shown in ProMap Settings.

Control URLs also work with JSON POST requests. Use `POST /v1/output/active` with `{"active":false}` or `POST /v1/output/intensity` with `{"value":0.5}`. `POST /v1/surface/{UUID}/active` controls one mask's visibility, `/blackout` controls its blackout flag, and `/intensity` sets its brightness. Get the UUIDs, assigned output, and current source path for each surface from `GET /v1/status`. Other controls include `GET` or `POST` `/v1/blackout/on`, `/off`, `/toggle`, `/v1/output/blackout/on`, `/off`, `/toggle`, `/v1/cue/next`, `/v1/cue/previous`, and `/v1/scene/{UUID}/take`. For FreeShow, a saved cue can also be recalled with `GET /v1/scene/take?name=Sunday%20Morning`; scene names must be unique, ignoring letter case. A JSON client can use `POST /v1/scene/take` with `{"name":"Sunday Morning"}`. The status response includes master intensity, active/blackout state, open outputs, scenes, and each surface's visibility, blackout, intensity, source and output assignment.

To let a phone or tablet control ProMap, enable **Allow access from this local network**, set a bearer token, and open `http://<Mac IP>:<port>/calibrate?token=<token>` on a trusted private network. The remote page can select a surface, edit its four corner coordinates, toggle blackout and take a scene. Remote HTTP is unencrypted, so disable network access after calibration. OSC remains localhost-only.

Enable **MIDI input** in Settings to learn controls from connected MIDI devices. Choose **Learn** beside blackout, next/previous cue or a saved scene, then press a MIDI note or button. Learned controls persist across launches. Notes trigger on press; CC controls trigger when their value rises through the midpoint. Use **Refresh Inputs** after connecting a controller. MIDI is disabled by default.

To add a live source, open the **+** menu beside **Clip Grid** and choose a camera or external USB capture device. macOS asks for camera permission the first time. The source tile shows a low-rate live thumbnail even before it is assigned to a surface. Assign it like imported media. Use **Camera Access…** in the same menu to request or check access. On a live source tile, open the gear menu to choose a supported resolution and common frame rate; ProMap remembers the choice for that device. The tile shows when the capture device disconnects; reconnecting the same device automatically rebuilds its capture session.

Surfaces render in the order listed. If mapped surfaces overlap, later surfaces appear above earlier ones. The composition layer stack can be assigned to a surface, and each layer's source transform is applied independently before that surface's mapping and mask.

## Calibrate on the projector

1. Connect the projector and choose it from the **Output** menu. Opening a physical display creates a borderless fullscreen output.
2. Choose **Grid**, **Checkerboard**, **Color Bars**, or **Surface Outlines** from the mapping preview toolbar. The pattern appears in the editor and output; **Off** returns to media playback.
3. Stand near each physical surface and adjust its white corner handles. Select a polygon mask and move its amber vertices to follow the physical edges.
4. Use each mask's four output corners to keystone-correct its projection independently.
5. Lock each calibrated surface. Choose **Off** before a service so calibration graphics do not appear in the program.
6. Save a mapping preset from **Project → Save Mapping**. Use **Project → Save Show** to include layers and scenes as well.
7. For a service, keep one physical output open and assign the cross and ceiling masks to that output. Their geometry and mask paths stay independent, so each source can be keystoned onto its own part of the same projector image. Use FreeShow HTTP actions to recall your scene, change master intensity or trigger blackout without touching the mapping.

Right-click inside either the virtual window or fullscreen output and select **Close Output**. A virtual output is a windowed simulation at a preset or custom render resolution; it is not a macOS display device. The status bar reports the selected GPU and successfully presented frame rate. Its **LATE** percentage estimates the share of frame intervals longer than 1.5 times the selected target interval; it is a timing estimate, not GPU utilization. Open **Diagnostics** for measured Metal GPU command time when available, process CPU and memory, cached texture allocation, media input resolutions/rates, display connection state, and NDI/Syphon status.

In **ProMap → Settings → General**, choose **Performance**, **Balanced** or **Full Detail** to set output frame rate and editor preview rate/resolution together. The Performance profile uses 30 fps output and a half-resolution 10 fps preview; Balanced uses 60 fps output and a 75% 15 fps preview; Full Detail uses 60 fps output and a full-resolution 30 fps preview. Adjusting an individual rate or preview scale switches the setting to **Custom**. These profiles do not reduce physical or virtual projector output resolution or change saved mapping coordinates.

Open **ProMap → Settings** and enable **Keep output above the macOS menu bar** to cover the menu bar on the output display while the output is open. This places the output above ordinary windows on that display as well.

## Playback and show files

Open the **Playback** workspace to use the separate cue list and switcher controls. Enter a name and capture the current program to save layer order, enabled state, opacity, video playback position, per-source audio state, and each mask's source assignment, visibility, blackout, brightness/opacity and colour correction. Clicking a cue immediately stages it in Preview while Program stays live. **TAKE SCENE** sits above the Program monitor and flashes red while a cue is staged. Use **Cancel** to clear preview. Scene video previews are muted. Right-click a cue to preview, take, reorder or delete it. Add operator notes and an optional per-cue advance duration in Cue Details. Enable **AUTO** before timed advancement runs. Choose Cut, Dissolve or Dip to Black and adjust the transition duration beneath the monitors. Layer opacity and video audio crossfade, while direct mask source or visual-state changes fade out and back in through black. Calibrated corners and mask geometry remain fixed.

Enable NDI discovery in **ProMap → Settings → NDI I/O**, choose the receive bandwidth and disconnect fallback, then use **+** beside **Clip Grid** to add a discovered network source. To add an unlisted source, enter its NDI source name and URL/address in the same Settings page, save it, then select it from the Clip Grid **+** menu. Saved manual sources appear below the form and can be removed there. Sources appear as live audio/video clips and can be assigned to a mask or layer like other media. Their tiles report received video resolution and frame rate. New NDI sources start muted; open a clip's speaker control for a live audio meter, mute/level controls and a 0–500 ms audio delay slider for A/V sync. The delay affects audio only; its video remains live. Source audio settings persist in scenes and show files. NDI input requires the macOS NDI runtime; ProMap loads it dynamically and does not bundle the runtime. The official NDI SDK is available [from NDI](https://ndi.video/for-developers/ndi-sdk/download/).

To send the mapped program to another NDI receiver, open **ProMap → Settings → NDI I/O**, enable **Send the projector output over NDI**, and choose a source name. ProMap streams the most recently selected open physical or virtual output at up to 30 fps; all surfaces assigned to that output, including their masks and keystone, are included. The stream is video-only. The NDI status in Settings and the master-output panel reports sender readiness and errors. Disable NDI output when you do not need the network stream.

To receive a Syphon server, enable **Syphon input discovery** in **ProMap → Settings → Syphon I/O**, then choose **Clip Grid → + → Syphon Sources**. Add each server separately and assign it to the cross, ceiling, or another mask. The input connects through the bundled Syphon framework, so no extra framework install or capture hardware is required. Syphon inputs have a live signal status and their server identity is saved with shows and mappings; the source app must be running again when you reopen a show.

To publish a projector canvas to a Syphon client, enable **Publish the projector output over Syphon** in that settings page and choose a server name. ProMap sends the currently selected open output, including all of its mapped surfaces, using the Metal output texture. The status changes when a Syphon client connects. Disable the option when the receiving app no longer needs the feed.

The left/right cue buttons step through the captured scene list. ProMap also writes a local autosave every 30 seconds after you change the show. If an autosave is present at the next launch, choose **Restore** or **Start Fresh**.

Use **Project → Save Show** to store the current mapping, layers and captured scenes in a JSON show file. ProMap autosaves every 30 seconds and after changes settle, keeping the previous valid recovery copy; on launch choose **Restore** to load the latest readable snapshot. If the previous run ended unexpectedly, the recovery prompt identifies that and offers the same last-valid snapshot. For a portable project, choose **Export Portable Show Bundle**, select a parent folder and bundle name. ProMap creates a `.promapshow` folder with `Show.json` and a `Media` folder. Load it with **Load Show or Bundle**; media references resolve relative to the bundle. Missing media stays linked to the original path and capture devices remain live source references. For ordinary JSON shows with moved files, choose **Locate Media Folder…** when prompted; ProMap relinks files only when a filename has one match. **Save Mapping** stores surface geometry, mask, colour correction and effect settings.

## Current limits

- Multiple physical and virtual output canvases are supported, with surfaces assigned to one canvas each. Virtual outputs are windowed simulations, not system-level virtual monitors.
- Each surface supports a main polygon plus up to seven additional include/cutout paths in normalized source coordinates. Each output also supports up to eight feathered post-warp exclusion polygons.
- Corner and mask coordinates use normalized percentages. Source zoom, position, rotation and flip are available; pixel-coordinate entry and multi-surface geometry operations are not.
- Mesh warp supports regular 2×2 through 6×6 cell grids. Multi-point selection, custom mesh topology and higher grid densities are not available.
- GPU blur, chroma/luma key, brightness, saturation, hue rotation, tint, sharpen, vignette, threshold, grayscale, sepia, invert and pixelation are available in surface and per-layer stacks. User-saveable presets work across layers and surfaces; animated parameters are not available yet.
- Live capture supports a low-rate media-library thumbnail, device format selection, disconnection status and automatic reconnection by device ID. Capture-device audio is not available. Video and NDI source audio have per-source mute/volume, a master level, selectable Core Audio output routing and scene-synchronized fades. NDI inputs and local video clips have live audio meters and configurable audio delay; format support is reported in the clip controls.
- Syphon video input/output is built into ProMap with a universal Intel/Apple Silicon framework. It shares video frames with compatible macOS apps; it does not provide network transport or audio. Validate the selected output orientation and sustained frame rate with the actual Syphon peer before a live service.
- Remote calibration currently offers numeric corner entry; drag handles, mask-vertex editing, output assignment and edge-blend setup remain in the native editor only.
- The preview/program workflow currently stages scenes only; it does not provide a fully independent media launcher or transition-curve editor.
- JSON show files reference media paths. Portable bundles copy available local media; missing files and capture-device references remain external. Folder relinking matches unique filenames and does not resolve ambiguous duplicate filenames.
- Validate calibration and sustained playback on the intended projector and Intel MacBook Pro before using ProMap for a live service.
